# TAMP capability mock

This example shows the `cap.tamp.v1` request shape for a future PDDLStream/PyBullet-backed adapter.

It uses the built-in deterministic mock adapter named `mock-pddlstream-pybullet`. It does not require PDDLStream or PyBullet.

Run:

```bash
./build/core-only/muslisp examples/capabilities/tamp_pybullet/mock_tamp_solve.lisp
```
