# motion capability mock

This example shows the `cap.motion.v1` request shape for a future MoveIt-backed adapter.

It uses the built-in deterministic mock adapter named `mock-moveit`. It does not require ROS2, MoveIt, or a robot arm.

Run:

```bash
./build/core-only/muslisp examples/capabilities/moveit_motion/mock_validate_target.lisp
```
